# 딜 데스크 (DEAL DESK)

대체투자금융2팀 딜·대주 관리. 프로젝트별로 **어느 대주를 태핑했고 반응이 어땠는지**를 팀이 함께 보고,
**자주 보내는 대주 리스트**에서 바로 골라 **받는 사람마다 단독 메일**을 한 번에 보낸다.

## 무엇을 하나

| 화면 | 하는 일 |
|---|---|
| 홈 | 진행 딜 카드(목표 대비 승인·심의·검토 막대), 7일 안 심의, **팔로업 필요**(태핑·자료송부 뒤 5일, 검토중 10일 소식 없음), 팀 최근 활동 |

### 메일은 언제나 '한 명에 한 통'

단체 메일·숨은참조 방식은 **없다**. 받는 사람마다 그 사람만 To 에 들어간 메일을 따로 만든다.

- **Outlook 으로 한 번에 (PC, 기본)**: 사이트에서 '발송 묶음'(.ddmail.json)을 내려받고 `Outlook발송.cmd`(처음 한 번 내려받기)를 더블클릭
  → 내려받기 폴더의 가장 새 묶음을 읽어 목록을 보여 주고, **S** = 한 통씩 바로 보내기 / **D** = 임시보관함에만.
  보내는 계정은 딜 데스크에 등록한 이메일과 같은 Outlook 계정. 끝나면 묶음 파일을 지울지 묻는다.
- **하나씩 열기**: Outlook 창(.eml, 첨부 포함) · Outlook 웹 · Gmail · 기본 메일 앱(휴대폰). '다음 메일 열기'로 차례로.
- 보낸 뒤 **발송 기록 남기기** → 활동에 남고, 태핑 보드에서 미접촉·태핑 → 자료송부, 보드에 없던 대주는 자료송부로 추가.
- 첨부는 그 PC 브라우저 안에서만 쓰이고 저장소로 올라가지 않는다.

## 구조 · 보안

```
web/            GitHub Pages 로 올리는 정적 사이트 (데이터 없음)
  config.js     API_URL(Apps Script 주소) · 회사·팀 이름. 비우면 '시험 모드'(이 브라우저 localStorage)
  core.js       암호화·저장소·엑셀(xlsx 직접 생성)·.eml
  app.js        로그인·홈·딜 목록·대주 서랍·엑셀·카톡
  deal.js       딜 화면(요약·보드·개요·활동)·딜 입력 창·태핑 리스트 가져오기
  extract.js    PDF·워드·엑셀 → 줄, 딜 정보 뽑기(extractDeal)
  vendor/pdfjs  pdf.js 4.10 (Apache-2.0) + cmaps
  app-more.js   대주·리스트·메일·활동·설정
  seed.js       기본 대주 목록(기관 이름·유형만, 180여 곳)
  tools/Outlook발송.cmd   Outlook 개별 발송 도우미 (cmd 안에 PowerShell)
apps-script/dealdesk.gs   팀 공용 저장소 (구글 시트)
serve.js        로컬 시험 서버 (node serve.js 8130)
```

- 중도금 주선 리스트(jungdo.html)와 같은 방식. **모든 레코드를 브라우저에서 팀 키 K 로 AES-GCM 암호화**해서 보낸다.
  구글 시트에는 암호문 + 레코드 번호·종류·시각·고친 사람 번호만 남는다.
- 로그인 = 회사 이메일 + 개인 비밀번호. 비밀번호(PBKDF2 20만 회)로 K 를 감싼 꾸러미를 시트 `keys` 에 둔다(이메일은 해시로만).
  팀원 등록 = 관리자가 임시 비밀번호로 꾸러미 하나 추가. 중지 = 꾸러미 삭제.
- 요청 허락 표(tok)는 K 에서 뽑는다. 팀 만들 때 Apps Script 속성에 한 번 저장되고, 모든 읽기·쓰기가 확인한다.
- 동시에 고치면 서버가 `conflict` 로 되돌려 보내고, 브라우저가 최신본에 내 변경을 다시 얹어 저장한다. 40초마다 + 창에 돌아올 때 새로 불러온다.
- **한계**: 중지한 사람이 예전에 K 를 따로 빼 두었다면 막을 수 없다(키 교체는 아직 없음). 팀 키를 잃으면(모두 비밀번호를 잊으면) 복구 불가 → 설정 › 팀 키 보기로 한 번 보관.

## 처음 띄우기

1. 구글 스프레드시트 새로 만들기 → 확장 프로그램 › Apps Script 에 `apps-script/dealdesk.gs` 붙여넣고 저장
2. 배포 › 새 배포 › 웹 앱 / 실행 계정: 나 / 액세스: 모든 사용자 → 나온 `…/exec` 주소를 `web/config.js` 의 `API_URL` 에
3. `web/` 을 GitHub Pages 로 올린다 (데이터가 없으니 공개 저장소여도 된다. 검색엔진 차단 meta 있음)
4. 사이트 첫 화면 '팀 만들기' → 만든 사람이 관리자 → 설정에서 '기본 대주 목록 불러오기', 팀원 등록(임시 비밀번호를 카톡으로 전달)
5. 기존 연락처 엑셀(예: `(미래에셋증권) 중도금대출 대주 연락처.xlsx`)은 대주 › 엑셀에서 붙여넣기 → '새 리스트 만들기'로 리스트까지 한 번에

Apps Script 코드를 고치면 **배포 › 배포 관리 › 새 버전**으로 다시 배포해야 반영된다(주소는 그대로).

## 로컬 시험

`.claude/launch.json` 의 `deal-desk` (node serve.js 8130). config.js 의 API_URL 이 비어 있으면 시험 모드라 이 브라우저 안에만 저장된다.
시험 데이터를 지우려면 브라우저 개발자 도구에서 localStorage `dealdesk-mock-store` 삭제.
